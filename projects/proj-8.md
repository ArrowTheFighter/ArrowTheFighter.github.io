Spirit Web is a tech demo for a dungeon crawler with visual scripting capabilities.
Players can use visual scripting to completley change how their player interacts, enabling them to move further, attack at a distance or even control enemies.
I built this game from scratch and developed all the character controller and visual scripting to work seemlessly together.

View the github page here: <https://github.com/ArrowTheFighter/spirit-web>
Try the game out here: <https://arrowthefighter.itch.io/spirit-web-demo>
